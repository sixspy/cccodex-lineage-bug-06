## 责任组切换（旁路账册单轨）

采集组 → 仓建组 的改组只有一种正确性形态：**改组那一刻把节点与组指纹锁进旁路账册，账册只增不改**。

- 改组由 `/api/owner_group/switch` 一次事务写完；失败返回短句（如 `改组账册已锁定，不可再改`）。
- 账册落定后，改节点责任组、改组权限指纹都会判成「拧花」：清洗入库（`transform_kind=清洗` 的边发布）被拦，覆盖抽检显示「有缺口」，不再虚过。
- 展示与库表同源：节点目录亮改组标记与组号，覆盖进度旁挂组号与改组状态；仅改组名展示不写权限包一律失败。
- 不做「旧组历史轨 + 新组现行册」双写两轨，避免进度读权出现两套口径。
